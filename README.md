# حضور و غیاب من (Hozor)

اپلیکیشن موبایل حضور و غیاب با **تقویم شمسی**، ثبت ورود/خروج و گزارش کارکرد — دقیقاً بر اساس طرح داشبوردی که فرستادی.

- یک کدبیس، دو خروجی: **وب‌اپ نصب‌شدنی (PWA)** + پروژه آماده برای ساخت اپ نیتیو **اندروید و آیفون** با Capacitor.
- کاملاً فارسی، راست‌به‌چپ، فونت وزیرمتن، اعداد فارسی.

## امکانات

| بخش | توضیح |
| --- | --- |
| تقویم ماهانه | نمای هفت‌ستونی (شنبه تا جمعه) با شیفت، ساعت ورود/خروج، کارکرد، کسر کار، تاخیر و اضافه‌کاری هر روز؛ در موبایل به‌صورت لیست روزانه نمایش داده می‌شود |
| کارت‌های آماری | ساعت کاری، اضافه‌کاری تایید‌شده/تاییدنشده، کسر کار جلسات، خارج از شیفت، تعطیل‌کاری، تاخیر ماه، مرخصی و کارکرد کل |
| ثبت دستی روز | انتخاب روز از **تقویم شمسی** و وارد کردن دستی ساعت ورود/خروج (تا ۴ بازه در روز، برای استراحت یا کار دوباره)، مرخصی، تایید اضافه‌کاری و توضیح — برای امروز، دیروز یا هر روز از ماه‌های قبل |
| ثبت سریع | دکمه بزرگ با ساعت زنده، محاسبه لحظه‌ای کارکرد، حذف آخرین ثبت، ثبت اختیاری موقعیت مکانی |
| لمس روز در تقویم | صفحه‌ای باز می‌شود که می‌پرسد «ورود یا خروج؟»؛ بعد ساعت را می‌زنی و ثبت می‌شود. گزینه «ویرایش کامل روز» هم همان‌جاست (چند بازه، مرخصی، توضیح، پاک کردن) |
| شیفت شبانه (تا بامداد) | اگر ساعت پایان شیفت کوچک‌تر از شروع باشد (مثلاً ۰۸:۰۰ تا ۰۴:۰۰)، همه‌چیز به همان روز کاری نسبت داده می‌شود؛ ثبت ۰۲:۰۰ بامداد در روز بعد جدا حساب نمی‌شود |
| کنترل خروج فراموش‌شده | روزهایی که فقط ورود ثبت شده با برچسب «خروج ثبت نشده» مشخص می‌شوند و کارکرد تا پایان شیفت محاسبه می‌شود، نه تا نیمه‌شب |
| گزارش‌ها | نمودار کارکرد روزانه، ریز کارکرد، جمع‌بندی و میانگین‌ها |
| خروجی اکسل | فایل `.xlsx` واقعی (RTL) با همه روزهای ماه + جمع‌بندی؛ خروجی CSV هم موجود است |
| پروفایل | نام، واحد، ساعت شیفت، استراحت روزانه، انتخاب روزهای تعطیل هفته، بازنشانی دادهٔ نمونه |
| آفلاین | همه داده‌ها در حافظه دستگاه (`localStorage`)؛ سرویس‌ورکر PWA برای نصب و کار بدون اینترنت |

## نصب اپ اندروید

آخرین نسخه آماده: **[بخش Releases](https://github.com/mazodimobinhost-creator/hozor/releases/latest)**

1. فایل `hozor-x.y.z.apk` را روی گوشی اندروید دانلود کن.
2. اگر پیام «نصب از منابع ناشناس» آمد، اجازه بده.
3. نصب کن. از این به بعد هر نسخه جدید روی همین اپ به‌روزرسانی می‌شود و اطلاعات می‌ماند.

نسخه iOS: همین اپ را با Safari به صفحه اصلی اضافه کن، یا با Xcode بساز (`MOBILE.md`).

## به‌روزرسانی از داخل اپ

- **PWA:** سرویس‌ورکر نسخه جدید را پیدا می‌کند و پیام «نسخه جدید اپ آماده است — بروزرسانی» بالای صفحه می‌آید.
- **اپ اندروید/آیفون:** هنگام باز شدن اپ، نسخه‌ها با GitHub Releases مقایسه می‌شود؛ اگر نسخه تازه‌تری باشد بنر «نسخه x آماده است — دریافت» نمایش داده می‌شود. مسیر دستی: پروفایل ← «بررسی بروزرسانی».
- APK با یک **کلید امضای ثابت** (`signing/hozor-release.p12`) ساخته می‌شود تا نسخه جدید روی نسخه قبلی نصب شود، نه به‌صورت اپ دوم.

### انتشار نسخه جدید

```bash
# نسخه را در package.json بالا ببر (مثلاً 1.0.2)، سپس:
git tag v1.0.2 && git push origin v1.0.2
```

ورک‌فلوی `Build Android APK` خودش APK امضاشده را می‌سازد و روی همان تگ به Releases می‌چسباند؛ اپ‌های نصب‌شده هم بلافاصله آن را پیشنهاد می‌دهند.

## اجرا

```bash
npm install
npm run dev        # http://localhost:4173
npm run build      # خروجی production در dist/
npm run preview    # پیش‌نمایش build
```

## ساخت اپ اندروید و آیفون

راهنمای کامل: [`MOBILE.md`](./MOBILE.md)

```bash
npm run build
npx cap add android      # و یا npx cap add ios
npx cap sync
npx cap open android     # ساخت APK / AAB در Android Studio
```

## محاسبات

- **کارکرد روز** = جمع بازه‌های ورود تا خروج (بدون استراحت‌های بین آن‌ها).
- **کارکرد داخل شیفت** = هم‌پوشانی کارکرد با بازه شیفت (پیش‌فرض ۰۸:۰۰ تا ۱۷:۰۰).
- **خارج از شیفت** = کارکرد منهای هم‌پوشانی با شیفت.
- **موظفی روزانه** = طول شیفت منهای استراحت روزانه (قابل تغییر در پروفایل).
- **شیفت شبانه:** اگر `پایان شیفت ≤ شروع شیفت` باشد، پایان به‌صورت «+۲۴ ساعت» در نظر گرفته می‌شود؛ مثلاً ۰۸:۰۰ تا ۰۴:۰۰ یعنی ۲۰ ساعت شیفت. ثبت‌های بامداد (۰۰:۰۰ تا ساعت پایان) به روز کاری قبل تعلق می‌گیرند.
- **تاخیر** = دیرتر از شروع شیفت بودن اولین ورود.
- **اضافه‌کاری** = کارکرد مؤثر (کارکرد + مرخصی + جلسه) منهای موظفی؛ در روز تعطیل، تمام کارکرد.
- **اضافه‌کاری تاییدنشده** = اضافه‌کاری منهای مقدار تاییدشده در همان روز.

## ساختار پروژه

```
src/
  lib/
    jalali.ts     تبدیل و قالب‌بندی تاریخ شمسی، اعداد فارسی
    calc.ts       محاسبه کارکرد، تاخیر، اضافه‌کاری و آمار ماه
    store.tsx     ذخیره‌سازی محلی + دادهٔ نمونه
    export.ts     خروجی اکسل و CSV
  components/     تقویم، کارت‌های آماری، صفحه ثبت، گزارش‌ها، پروفایل
  styles.css      طراحی واکنش‌گرا (RTL)
```

## حریم خصوصی

اطلاعات هر فرد فقط روی گوشی خودش ذخیره می‌شود؛ هیچ سروری در میان نیست. اگر بعداً نیاز به نسخه تیمی/سروری داشتی، لایه داده در `src/lib/store.tsx` تنها جایی است که باید به API وصل شود.
